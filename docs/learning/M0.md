# M0 — Kurulum ve iskelet: Bilimsel Özet
Tarih: 2026-11-07 · Commit aralığı: 1631575..90ea734 · Testler: core 1/1, web 1/1

## 1. Bu modülde ne inşa ettik
Bu modülde henüz FEM matematiği yok; projenin **iskeletini** kurduk. Git deposu başlatıldı ve GitHub'a bağlandı
(`yzd-info/FEM_STUDIO`). `core/` altında src-layout bir Python paketi (`fem1d`, `__version__="0.1.0"`) ruff + mypy +
pytest + hypothesis ile; `web/` altında Vite + TypeScript (strict) bir web uygulaması vitest (birim) ve Playwright
(e2e) ile kuruldu. Son olarak `Makefile` ve GitHub Actions CI (`python`, `web` işleri) eklendi.

## 2. Matematik
Yok — bu modül kapsam dışında. FEM'in sekiz aşaması M1'den başlayarak kurulacak (`docs/LEARNING.md` §2).

hangi kontrol mekanizmasının (CI, lint, tip kontrolü) kullanılacağına önce karar verilir. M0, geri kalan 7 günün
üzerine inşa edileceği bu temeldir — yanlış kurulmuş bir temel, ileride her modülde tekrar maliyet çıkarır.

## 6. Tuzaklar
- Yerel Python minör sürümü (3.14) ile Pyodide'in içerdiği Python sürümü (3.14.2) eşleşmezse, M6'da wheel
  yüklerken sessiz uyumsuzluklar çıkabilir — bu yüzden M0.1'de özellikle kontrol edildi.
- `make` Windows'ta varsayılan kurulu değildir (`ezwinports.make` ile eklendi); unutulursa `make check` komutu
  "command not found" ile başarısız olur, FEM ile ilgisi yoktur.

## 7. Varsayımlar ve sınırlar
M0'ın "doğruluğu" matematiksel değil, araçsaldır: CI yeşil, `make check` yeşil, lint/tip sıfır hata. Bu modülün
çıktısı bir sonraki modülün üzerine güvenle inşa edilebileceğinin kanıtıdır, FEM sonucunun doğruluğunun kanıtı değildir.

## 9. Hocanın sorabileceği sorular
- **S: Neden src-layout kullandık, düz `fem1d/` değil?** C: src-layout, paketin yanlışlıkla `sys.path`'teki
  çalışma dizininden değil, kurulu paketten import edildiğini garanti eder — testlerin gerçek paketi test ettiğinden
  eminiz.
- **S: `hypothesis` neden M0'da eklendi ama henüz kullanılmadı?** C: M1.1'de Gauss kareleme testinde rastgele
  polinom katsayılarıyla property-based test yazılacak; bağımlılık M0'da hazırlanıyor, kullanımı M1'de başlıyor.
